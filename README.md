# Social Media Content Performance Analytics

## Project Overview
This project focuses on analyzing social media content performance using Excel and Power BI. The objective is to understand audience engagement, reach, followers, conversions, and content performance.

## Tools Used
- Microsoft Excel
- Power BI

## Project Workflow

### 1. Excel Analysis
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Data analysis and KPI calculations
- Identifying trends and performance patterns

### 2. Power BI Dashboard
- Interactive dashboard development
- KPI cards and visualizations
- Platform-wise and content-wise analysis
- Monthly engagement trends
- Performance status analysis
- Key insights from social media data

## Key Metrics
- Total Posts: 1,000
- Total Reach: 45.65 Million
- Total Engagement: 2.57 Million
- Average Engagement Rate: 5.65%
- Total Followers: 254,960
- Total Conversions: 102,285

## Project Files
- Excel Analysis: Data cleaning and analysis workbook
- Power BI Dashboard: Interactive `.pbix` report
- Final Dashboard PDF: Dashboard preview

## Conclusion
This project helped analyze social media performance and identify patterns in audience engagement, content reach, and conversions using Excel and Power BI.
